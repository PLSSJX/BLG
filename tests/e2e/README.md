# 端到端测试

两个脚本都直接打本机正在运行的 MakiseToolkit（默认 127.0.0.1:8931），
所以**先启动应用**再跑。

    node tests/e2e/api.mjs     # 接口层：建项目/挂文件/版本/回滚/自动保存/导出/占用检测
    node tests/e2e/ui.mjs      # 界面层：画布渲染、单击编辑、路径高亮、Ctrl+Z、删除对话框、历史面板

约定：

* 两个脚本各自准备独立的临时项目目录（`D:\_e2e_*_<时间戳>`），跑完不自动删
* 全部通过时退出码为 0，有失败则非 0，最后一行为 `结果: x/y`
* 自动保存那一步要等 30 秒静默窗口，整个 api.mjs 大概 1 分钟
