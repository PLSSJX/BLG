# 端到端测试

三个脚本都直接打本机正在运行的 MakiseToolkit（默认 127.0.0.1:8931），
所以**先启动应用**再跑。

    node tests/e2e/api.mjs      # 接口层：建项目/挂文件/版本/回滚/自动保存/导出/占用检测
    node tests/e2e/ui.mjs       # 画布层：渲染、单击编辑、路径高亮、Ctrl+Z、删除对话框、历史面板
    node tests/e2e/header.mjs   # 外壳层：左上角按钮三种状态、新建对话框、删除项目

约定：

* 每个脚本用独立临时项目目录（\`D:\\_e2e_*_<时间戳>\`）和独立浏览器配置目录
* 全部通过时退出码 0，最后一行为 \`结果: x/y\`
* api.mjs 里有 30 秒静默窗口的自动保存测试，跑一轮约 1 分钟
