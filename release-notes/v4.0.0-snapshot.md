# Makise Toolkit 4.0.0 快照版（不稳定）

> ⚠️ **这是快照版，不是稳定版。** 功能能日常使用，但没经过长时间验证。
> 建议先在**新项目**上试，重要论文同时保留一份普通文件夹备份。

## 这次变了什么

定位变了：从「一堆工具的集合」改成「**用思维导图写论文、随时能回档**」。

- **项目**：思维导图式提纲，节点就是章节，每段正文写进项目里的 .md
- **版本**：每次保存留一版，可以整份回档，也可以只还原某个文件
- **文献**：检索 → 下载即入库 → 一键生成 GB/T 7714 / APA / IEEE / MLA / BibTeX / RIS
- **文档**：Word / Excel / Markdown / PDF 互转，扫描件走 OCR
- **AI**：可选，自带 API key，只把你点「问」的片段发到你填的端点
- **附加工具箱**：视频下载 / 音乐 / 剪辑 / 图片放大，**默认关闭**，设置里可开

## 数据安全（这次重点验证过的）

- 编辑中强杀进程 → 重启后正文和版本历史都在
- 断电模拟（直接改盘 + 强杀）→ 内容不丢，还能继续提交
- 回档到旧版本 → 再写 → 再回档：没有「幽灵内容」
- 15 次快速保存不漏存；100+ 版本时时间线 30–40ms、回档 30–50ms
- 一键备份：整个项目（含 .mt 版本库）打包成 zip，解开就能用
- 附件是**副本**：改项目里的文件不影响原文件

## 已知问题

- 自动更新检查在弱网下可能慢（已做并行 + 8 秒超时）
- OCR 的 Tesseract 自动下载在部分网络下会超时，可在设置里手动指定安装包
- 版本库目录（.mt）被手动删掉后能自动重建，但**历史版本会丢**（正文不受影响）

## 安装

下载 `MakiseToolkit-Setup-4.0.0.exe`（122 MB），双击安装。需要 Windows 10/11 x64。
