# 项目管理 · 当前状态（已完成）

## 结论

项目管理（方案 C：SQLite 快照历史，不依赖 Git）已接入 MT，装好可用。
单实例、自动保存、回滚、导出 Git 都验证过，端到端测试两轮全绿。

## 这次修掉的 bug

| 问题 | 原因 | 修法 |
|---|---|---|
| 重复启动出现一堆空白窗口 | WebView2 用户数据目录独占，第二个窗口初始化失败（0x8007139F） | 命名互斥量做单实例判定；第二次启动改为把已有窗口拿到前台 |
| 项目没有任何版本时自动保存永远不触发 | 巡检线程在 `rev-parse HEAD` 失败时直接 `continue` | HEAD 为空时不当失败处理 |
| 挂大文件报 "Strings must be encoded before hashing" | `hashlib.sha1(str)` 少编一次码 | 先 `encode("utf-8")` |
| 不能给主干挂附件 | 查节点时只遍历 `nodes`，漏了 `trunk` | 主干一起查（挂载 + 移除两处） |
| 文件被别的程序占用时照样提交 | 用 `os.open` 探测，Windows 下共享打开不会失败 | 改用 `CreateFileW` 独占方式探测（共享冲突 = 被占用） |
| `window_frame.py` 在 ctypes 回调里抛 NameError | 用了不存在的 `wt`（应是 `ctypes.wintypes`） | 显式导入并改正 |
| 点完节点按 Ctrl+Z 没反应 | 焦点在正文输入框，键盘处理直接 return | 输入框"脏"时才让位给文本撤销，否则走画布撤销 |
| 右侧编辑栏挡住画布右边的节点 | 常驻栏占了 400px，视野没重算 | 首屏渲染后重新 fitView，最小缩放抬到 0.62 |
| 底部工具栏按钮文字被挤成两行 | 按钮可收缩 | 按钮禁止收缩、整排换行 |

## 功能清单（实测通过）

* 创建项目（必须空文件夹，非空会明确拒绝）
* 主干 / 分支 / 关联线，单击节点在右侧常驻栏编辑
* 从主干到选中节点的路径高亮
* 挂文件（docx / 21MB 视频都试过，项目内镜像，源文件不动）
* 每次保存记一个版本（手动 + 30 秒静默自动保存）
* 整份回滚（会清理目标版本里没有的多余文件）、单文件还原
* 撤销 / 重做（Ctrl+Z / Ctrl+Shift+Z，以及顶部按钮）
* 版本历史面板：按天分组、回到某个版本、导出为真实 Git 仓库
* 文件被占用时拒绝保存并说明是哪几个文件
* 删除节点：应用内对话框确认，可连 .md 一起删

## 已知限制

* 大文件（>5MB）只记指纹不存内容，回滚时会跳过并弹窗说明
* WebView2 的用户数据目录仍是全局唯一，所以同一份安装只能开一个窗口

## 这一轮补上的

* **分支合并**：快照库自己做三方合并（公共祖先 → 逐文件取改动；同一段文本两边都改会报冲突并保留当前分支内容）
* **历史瘦身**：版本历史面板的「清理历史数据」，删掉已删分支留下的孤立版本和无引用内容块
* **大文件回滚提示**：回滚时被跳过的文件会弹窗列出来
* **节点结构纳入版本库**：.mt/graph.json 现在跟着版本走，回滚能连节点树一起恢复
* **写文件按字节**：不再被 Windows 换行转换改成 CRLF
* **编辑栏宽度可拖动**：拖左边缘改宽窄（320~760），双击恢复默认，宽度记在本地
