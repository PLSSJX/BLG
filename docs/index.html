功能

写作时常卡在两处：不确定接下来该写什么，以及改动过多后难以回到从前的状态。这个工具主要针对这两点。

提纲就是正文

一个节点即一个小节，内容直接写入并保存为 .md 文件。节点之间可以连线， 标注“支撑”“对照”等关系。提纲无需一次想全，可随写作增补。

一个节点 = 一个 .md

存一次，留一版

手动保存与自动保存都会生成版本。版本历史按日期排列，可整份回退， 也可只恢复其中某一个文件。

退回之前先看清楚改了啥

转文档

Word、Excel、Markdown、PDF 之间可相互转换，全部在本机完成。 每种 PDF 能否转换、转换后是否丢失版式，界面上均有说明；无法转换时会明确提示，不会输出空文件。

PDF 的脾气写在界面上

找论文、抄引用

接入 OpenAlex、Crossref、DOAJ、PubMed 等开放数据库，检索到即可下载， 下载后自动入库并按 DOI 去重。支持 GB/T 7714（中英文）、APA、IEEE、MLA， 以及 BibTeX、RIS 导出。

中文英文都不用手打

扫描件认字

扫描型 PDF 没有文字层，直接提取只能得到空白。程序会先渲染为图像再做识别， 默认调用 Windows 自带 OCR 引擎，无需额外安装。

不用下载模型

想问就问一句

提问时先从你的笔记中检索相关段落，再连同问题一起发送到所配置的接口。 可以关闭该功能；也可以配置多个接口，DeepSeek、OpenAI、本地 Ollama 均可。

Key 自己填，程序不带服务

使用流程

从检索资料到完稿，不必在多个工具之间切换，也不必担心某天打开时草稿丢失。

搜论文→ 下回来进库→ 认字 / 转格式→ 挂到对应小节→ 写正文→ 存一版→ 不对就退回去

正文是普通的 Markdown 文件，位于你指定的文件夹中。也可以用 Typora、VS Code 直接编辑， 程序会识别这些改动。

界面

启动后直接进入你的提纲，没有欢迎页，也没有需先行阅读的统计数据。

数据安全：已用脚本逐项验证

论文写作最怕稿件丢失。以下项目均为自动化脚本的实际运行结果，不是推测。

能力边界

以下限制在界面中同样标明，使用前即可了解。

还原 PDF 版式不支持。提取的是文字，分栏与表格会错乱；需要原版式请直接打开原 PDF。
加密 PDF无法读取，会明确提示需要密码，不会输出空文件。
扫描件识别准确率取决于原图清晰度与系统语言包；图像模糊时识别率明显下降。
AI 服务程序不内置模型，需自行填写兼容 OpenAI 的接口地址。
其他平台目前仅支持 Windows，依赖 WebView2 与系统 OCR。
多人协作不支持。项目是本地文件夹，多人修改同一份建议用 Git 自行管理。

常见问题

稿件保存在哪里创建项目时选择的文件夹。程序只会在其中增加一个 .mt 目录用于存放版本，其余均为普通 md 文件与附件。
是否会上传文件不会。下载、转换、识别与检索均在本机完成；仅在你主动提问时，命中的片段才会发送到所配置的接口。
版本库损坏怎么办程序会将损坏的库改名留档并新建空库，正文不受影响。建议定期使用「备份」导出 zip。
为什么找不到下载功能本程序以论文写作为主线，视频、音乐、剪辑、图片放大已归入「其他功能」，默认不显示，可在设置中开启。
