能干什么

写论文卡住的地方通常就两处：不知道该往下写什么，以及改乱了不知道怎么退回去。这程序主要冲着这两件事来。

提纲就是正文

一张卡片是一个小节，卡片里直接写内容，存成 .md。卡片之间能拉线， 标“这块支持那块”“这两块对着说”。提纲不用一次想全，边写边加。

一张卡片 = 一个 .md

存一次，留一版

手动存会留版本，自动保存也留。历史里按天排着，想退回哪一版直接退。 整个项目能退，单个文件也能单独拿回来。

退回之前先看清楚改了啥

转文档

Word、Excel、Markdown、PDF 之间互相转，都在本机算。哪种 PDF 能转、 哪种转了会丢格式，界面上直接写着，转不了会直说，不会给你一个空文件。

PDF 的脾气写在界面上

找论文、抄引用

接的是 OpenAlex、Crossref、DOAJ、PubMed 这些开放库，搜到就能下， 下载完自动进库，同一个 DOI 不会重复。引用格式有国标、APA、IEEE、MLA， 也能导 BibTeX 和 RIS。中英文的国标格式都按规矩来。

中文英文都不用手打

扫描件认字

扫描出来的 PDF 里头没有文字，直接抽只能得到空白。这里先把它渲成图再认字， 默认用 Windows 自带的识别，不用另外装东西。

不用下载模型

想问就问一句

找一个问题，先把相关的段落从你自己的笔记里翻出来，连同问题一起发给你填的接口。 嫌吵关掉也行，不填接口就当没这功能。支持填多个，DeepSeek、OpenAI、本地 Ollama 都行。

Key 自己填，程序不带服务

一般怎么用

从找资料到交稿，中间不用换来换去。也不用担心哪天打开，草稿没了。

搜论文→ 下回来进库→ 认字 / 转格式→ 挂到对应小节→ 写正文→ 存一版→ 不对就退回去

正文是普通的 Markdown，躺在你选的那个文件夹里。想用 Typora 或 VS Code 改也随意， 回程序里它认。

界面长这样

打开就是你的提纲，没有欢迎页，也没有一堆统计数据要先看。

做不了什么

下面这些都写在界面里了。先讲明白，省得你用到一半才发现。

还原 PDF 的版式不干。抽出来的是文字，分栏和表格会散。要看原样就开原文件。
加密的 PDF打不开，会告诉你缺密码，不会塞给你一个空文件。
扫描件认得准不准看原图清不清楚、系统装没装语言包。太糊的件认错很正常。
AI 服务程序里没有模型。要问就自己填一个兼容 OpenAI 的地址。
别的系统只有 Windows。它靠 WebView2 和系统自带的识别，换平台得重做。
多人一起改没有这功能。项目就是个本地文件夹，几个人改同一份建议用 Git。

常被问到

我的稿子到底存在哪就是你建项目时选的那个文件夹。程序只在里面多放一个 .mt 目录存版本，别的都是普通 md 和附件。
会不会偷偷上传不会。下载、转格式、认字、检索都在你机器上。只有你主动点“问一句”，命中的那几段才会发到你填的地址。
版本库要是坏了呢程序会把它改名留档，再建一个空的新库，稿子照样在。真怕出事，就偶尔用“一键备份”打个 zip。
为什么找不到下载功能这程序现在是写论文用的。视频、音乐、剪辑、图片放大都收进“其他功能”了，默认不显示，设置里能打开。
